2026-19-10 (06:30pm) - System tray & v1.0.0 release - Version 1.0.0
- New system-tray mode (--daemon): a panel icon (StatusNotifierItem) with a menu
  to mute, change volume, switch sound packs, open the TUI, and quit. Implemented
  directly on D-Bus (src/tray) - no Qt/GTK/appindicator dependency. libdbus is
  auto-detected; without it the TUI still builds, just with no tray.
- New control socket (src/control): the daemon hosts a small Unix-socket protocol
  so a terminal UI can drive the running instance instead of starting a second
  audio listener.
- "Open TUI" now opens a terminal running `wayclack --tui --attach`, which drives
  the existing daemon. Closing it detaches; the tray keeps running. One process,
  one keyboard listener. Added the --attach flag.
- Tray "Quit" stops the daemon and any attached TUI; an attached TUI detects the
  daemon going away and exits cleanly.
- Shared headless core (src/app) so the TUI and the tray daemon drive the same
  audio + listener instead of duplicating pack/volume logic.
- Added --tui / --daemon (--headless) mode flags.
- Opened the keyboard device with O_CLOEXEC so spawned terminals do not inherit
  the input-device descriptor.
- Per-user installer (scripts/install.sh): installs the binary, the logo into the
  icon theme, an application launcher (.desktop) and an optional autostart entry.
- Version bumped to 1.0.0, shown via --version.
- Fixed a broken mainwindow.cpp left with merge-conflict markers.

2026-19-10 (05:40pm) - Interactive TUI - Version 0.2.0
- New terminal dashboard (src/cli) with volume bar, mute, live keystroke feed,
  pack switcher and status panel. Plain C++ (ANSI + raw termios), no extra deps.
- Keyboard detection is now scoring-based (src/discovery): finds built-in
  laptop keyboards (i8042/serio, "AT Translated Set 2 keyboard") as well as USB
  keyboards, down-ranks mice that expose a HID keyboard interface, and rejects
  button/media-only nodes. Returns a stable by-id/by-path link when available.
- Keyboard listener now runs on a background thread (start/stop) so the UI can
  drive it; shutdown is responsive via poll() and joins cleanly.
- Audio samples are cached per pack (no more Mix_LoadWAV on every keystroke) and
  chunks are freed properly; volume/mute are applied live.
- Device and pack autodetection (src/discovery); removed hardcoded personal paths.
  New CLI flags: --packs, --device, --mute.
- Removed dead Parser::parse() debug helper.
